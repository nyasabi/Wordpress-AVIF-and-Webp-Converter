# Simple AVIF / WebP Converter

## 主な機能

### 画像変換
- メディアライブラリの JPEG / PNG を AVIF・WebP に変換（フルサイズ＋各サムネイルサイズすべて）
- 変換エンジンは **Imagick を優先し、無ければ GD にフォールバック**
- JPEG の EXIF Orientation（回転・鏡像）を変換後の画像にも正しく反映
- AVIF・WebP それぞれ品質（1〜100）を個別に設定可能。品質を変更すると次回の一括変換で既存の派生ファイルが自動的に再変換される
- 変換後のファイルが元画像より大きくなった場合は配信・保存をせず、再エンコードを繰り返さないよう記録
- **メモリガード**：GD変換前に必要メモリを見積もり、`memory_limit` を超えそうな巨大画像はスキップしてエラー一覧に記録（デフォルトON。共有サーバーでの致命的エラー対策）

### 変換方法（3通り）
1. **新規アップロード時の自動変換**（設定でON/OFFでき、WP-Cron/Action Scheduler のキュー経由でバックグラウンド実行のためアップロードがタイムアウトしない）
2. **管理画面からのAjax一括変換**（ブラウザを開いている間だけ進行）
3. **バックグラウンド一括変換**（サーバー側で少しずつ処理し、ブラウザを閉じても進行を継続）

### フロントエンド配信
- `<img>` タグを `<picture>` に自動書き換えし、AVIF → WebP → 元画像（JPEG/PNG）の順にフォールバック配信
- **Lazyload**：全画像に `loading="lazy"` / `decoding="async"` を付与（デフォルトOFF。他プラグイン・サーバー機能との二重適用に注意）
- **LCP画像の優先読み込み**：ページ先頭N枚をlazyload対象から除外し `fetchpriority="high"` を付与。投稿・固定ページのアイキャッチは `<link rel="preload">` で先読み（デフォルトON）
- **画像サイズ属性の補完**：`width`/`height` の無い `<img>` に添付メタから寸法を自動付与し、レイアウトシフト（CLS）を軽減（デフォルトOFF）

### 管理・運用
- 累計削減容量をダッシュボードに表示（SQLレベルのアトミック更新で同時実行時の計上漏れを防止）
- メディア一覧・詳細画面に変換状況（対応フォーマットバッジ／削減量）を表示
- 変換に失敗した添付ファイルの**エラー一覧**を管理画面に表示し、個別に再試行・履歴クリアが可能
- 添付ファイル削除時に `.avif` / `.webp` 派生ファイルと累計削減量を自動でクリーンアップ
- プラグイン**アンインストール時**に派生ファイル・postmeta・オプション・スケジュール済みジョブをすべて削除

## インストール

1. `simple-avif-converter.php` をプラグインとして WordPress にインストールし、有効化します
2. 管理画面の **「AVIF / WebP」** メニューを開き、サーバーの対応状況（AVIF対応／WebP対応）を確認します
3. 変換フォーマット・品質・自動変換の有無などを設定して保存します
4. 既存のメディアライブラリを変換する場合は「既存画像を一括変換」または「バックグラウンドで一括変換」を実行します

## 設定項目一覧

| 項目 | 説明 | デフォルト |
|---|---|---|
| AVIF / WebP 変換 | 各フォーマットの有効/無効（サーバー非対応時は選択不可） | サーバー対応状況に依存 |
| AVIF品質 | 1〜100（推奨 40〜55） | 50 |
| WebP品質 | 1〜100（推奨 70〜82） | 78 |
| バッチ件数 | 一括変換で1回に処理する件数（1〜20） | 3 |
| 自動変換 | 新規アップロード時に自動変換するか | OFF |
| フロント配信 | `<picture>` によるAVIF/WebP配信 | ON |
| Lazyload | 全画像への `loading="lazy"` 付与 | OFF |
| LCP画像の優先読み込み | 先頭N枚を優先読み込み・アイキャッチをpreload | ON（対象1枚） |
| 画像サイズ属性の補完 | width/height属性の自動付与（CLS対策） | OFF |
| メモリガード | 巨大画像の変換前メモリ見積もり・スキップ | ON |

## 注意事項

- **Lazyload機能**は、他プラグイン・テーマ・サーバー側の最適化機能（LiteSpeed Cache、Jetpack、CDNの画像最適化等）と重複すると画像が表示されなくなることがあります。いずれか1つでのみ有効にしてください。
- **画像サイズ属性の補完**は、テーマやページビルダーが意図的にサイズ属性を省略している場合はOFFのままにしてください。
- **メモリガード**はGDエンジンでの変換時のみ有効です（Imagickはピクセルキャッシュをディスクに退避できるため対象外）。
- 元のJPEG/PNGファイルは削除されません。変換は派生ファイル（`元ファイル名.avif` / `.webp`）として追加保存されます。
- **バックグラウンド一括変換**はサーバー側で動作しますが、WP-Cronはサイトへのアクセスを契機に実行されるため、アクセスの少ないサイトでは進行が遅くなることがあります（Action Scheduler が利用可能な場合はそちらを優先使用）。
